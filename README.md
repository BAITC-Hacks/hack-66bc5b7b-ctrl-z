| [Пример спецификации CSV](public/example-spec.csv) | Исходный файл для проверки разбора строк |

Для просмотра HTML-демонстрации скачайте файл и откройте его в браузере. Это отдельный сценарный показ на сохранённых данных, а не запущенное приложение с живым API. Презентации отражают этапы развития проекта; актуальное поведение определяется кодом и этим README.

## Как пользоваться

### Найти и сравнить товар

1. Откройте каталог или перейдите в консультант.
2. Выберите город, если важны местные остатки. Доступны «Все склады», Алматы, Астана, Шымкент, Актау, Атырау, Караганда, Усть-Каменогорск, Тараз и Талдыкорган.
3. Введите артикул, название или известные параметры. Например: `Подбери автомат Legrand`, затем `40 А`, затем `3 полюса`.
4. Уточните выдачу фильтрами или формой пошагового подбора.
5. Откройте «О товаре» для подробностей. Для сравнения отметьте 2–3 позиции.
6. Сохраните интересующий товар в избранное, чтобы вернуться к нему позже.

Уточнение `50 А` заменяет прежний номинал `40 А`, сохраняя другой контекст запроса. Слово `первый` позволяет выбрать позицию из последней выдачи. Короткое число без единицы измерения требует уточнения.

Избранное сохраняется в текущем браузере и синхронизируется между его вкладками. История хранит до 8 просмотренных товаров; блок «Вы недавно смотрели» показывает до 4 из них. Эти списки не являются аккаунтом покупателя и не синхронизируются между устройствами.

### Добавить товар в корзину

1. Нажмите «Добавить» у выбранной позиции.
2. Укажите количество в отдельной панели. В ней видны местный остаток, уже добавленное количество, кратность и предварительная сумма.
3. Нажмите «Проверить и добавить». Сервер запрашивает текущие данные и готовит предложение.
4. Проверьте товар, количество и сумму в панели подтверждения.
5. Подтвердите или отмените действие. Перед записью сервер повторно проверяет цену и доступность.
6. После успешного изменения откройте корзину через уведомление, кнопку в шапке или ссылку `/#cart`.

Если цена изменилась, потребуется новое согласие. Если товара недостаточно, сервер отклонит действие. Проверка учитывает количество, которое уже находится в корзине. Изменение количества и удаление также требуют подтверждения. Удаление существующей позиции не требует чтения внешнего каталога.

Предложение действует **5 минут**. Смена города отменяет ожидающее подтверждение, но сама по себе не меняет корзину.

### Оценить ответ

Под ответом ассистента доступны «Помогло / Не помогло». Повторное нажатие снимает оценку, выбор противоположной оценки заменяет её. Оценка привязана к ID ответа и восстанавливается вместе с серверной историей. Общей аналитической панели в текущей версии нет.

## Языки и валюты

В текущем интерфейсе язык связан с валютой отображения:

| Переключатель | Язык | Валюта |
| --- | --- | --- |
| Рус | Русский | RUB, рубли |
| Қаз | Казахский | KZT, тенге |
| Eng | Английский | USD, доллары США |

**Исходные цены каталога и серверная корзина хранятся в KZT.** RUB и USD — пересчёт для удобства просмотра, а не отдельные цены магазина или доступные способы оплаты. Независимого от языка переключателя валюты пока нет.

Переводятся интерфейс, типовые ответы, подписи документов и сообщения проверки. Названия товаров, исходные описания, значения характеристик и сообщения пользователя сохраняются на языке источника. Выбор языка хранится в браузере и синхронизируется между вкладками.

Поиск в каталоге поддерживает словарь казахских и английских выражений. Свободный диалог обслуживает EKT AI после подключения модели. Примеры запросов:

| Действие | Казахский | Английский |
| --- | --- | --- |
| Поиск | `Legrand автоматын таңда` | `Find a Legrand circuit breaker` |
| Запрос количества | `2 дана қос` | `add 2 units` |
| Подтверждение подготовленного действия | `иә, қос` | `yes, add` |
| Отмена | `бас тарту` | `cancel` |

Короткое неоднозначное `иә` не подтверждает добавление. Самый наглядный способ согласия — кнопка подтверждения подготовленного предложения.

### Откуда берётся курс

Маршрут `/api/rates` обращается к датированному XML-источнику Национального банка Казахстана на текущую дату по времени `Asia/Almaty`. Код проверяет дату, положительные значения USD/RUB и учитывает количество единиц валюты в поле `quant`.

- Интерфейс показывает дату курса и ссылку на источник.
- Браузер запрашивает обновление при открытии, затем каждые 5 минут и при возврате фокуса окна.
- Сервер хранит курс в памяти и при успешных запросах ограничивает повторное обращение к источнику интервалом в час, если дата не изменилась.
- При сбое сохраняется последнее доступное значение с предупреждением. После перезапуска сервер начинает с резервного снимка из `lib/currency.ts`; постоянного хранилища курсов нет.
- Карточки, сравнение, корзина и экспорт используют общую логику конвертации. Цена единицы округляется до двух знаков, затем умножается на количество.
- Фильтр цены работает в отображаемой валюте. При смене языка границы цены очищаются.

Резервные значения в коде датированы **23.09.2026**. Их нельзя принимать за свежий курс без проверки даты, показанной интерфейсом.

## Данные каталога и достоверность

В `data/catalog.json` находится снимок **100 карточек с первых 5 страниц API от 23.09.2026**: названия, артикулы, описания, цены, характеристики, склады, ссылки и изображения. Поиск и витрина работают по этой выборке. Сообщение «не найдено» не означает, что товара нет во всём магазине.

| Операция | Источник |
| --- | --- |
| Витрина, фильтры и поиск | Сохранённый снимок каталога |
| Подробная карточка и сравнение | Запрос деталей API, при сбое — отмеченный снимок |
| Подготовка и подтверждение добавления, изменение количества | Успешная проверка живого API обязательна |
| Экспорт | Подтверждённые строки серверной корзины и последний разбор спецификации |
| Изображения товаров | Публичные ссылки ekt.kz |

Противоречия данных выделяются предупреждением. Например, в поставляемой карточке ID `515291` номинал в названии и отдельном поле расходится. Приложение не должно выдавать такую карточку за проверенный инженерный подбор.

Предварительный аналог должен относиться к той же группе каталога и иметь минимум два известных совпавших критических параметра. Известное расхождение исключает кандидата. Отсутствие противоречий всё ещё не доказывает взаимозаменяемость; окончательное решение требует специалиста.

Сертификат выводится только при наличии подходящей HTTPS-ссылки из соответствующих полей EKT. Изображение товара не считается сертификатом. Если ссылки нет, ассистент предлагает уточнить документ у менеджера.

Ответы об оплате и доставке содержат ссылку на публичный источник EKT. Конкретные сроки, стоимость, минимальная сумма заказа и применимость условий требуют уточнения. Кратность отдельного товара не равна минимальной сумме всего заказа.

## Спецификации и вложения

Файл загружается через панель ввода консультанта. Можно также открыть «Спецификация» и вставить текст вручную. Разбор не добавляет позиции автоматически: покупатель проверяет распознанные строки, соответствие товаров и количество.

| Формат | Поддержка |
| --- | --- |
| TXT, CSV | Чтение текста и строк списка |
| DOCX | Извлечение текста документа |
| XLSX | Чтение значений ячеек без исполнения формул и макросов |
| PDF | Извлечение существующего текстового слоя |
| JPEG/JPG | Распознавание через настроенную модель с поддержкой изображений |
| Старые DOC/XLS | Нужно предварительно сохранить как DOCX/XLSX |
| PDF-скан без текста | Автоматического OCR такого PDF нет; можно ввести артикул вручную или подготовить JPEG для модели |

Ограничения: файл до **4 МБ**, PDF до **25 страниц**, извлечённый текст до **12 000 символов**, спецификация до **60 непустых строк**, пакетное действие до **20 выбранных строк товаров**. Повторяющиеся товары в пакете объединяются по ID, их количества суммируются. Пакет подтверждается целиком: ошибка одной позиции не должна приводить к частичному добавлению.

Простой формат:

```text
Артикул;Количество
200300285_;2
200300274_;1
```

Точное совпадение артикула подставляет товар. Если совпадение неоднозначно, покупатель выбирает кандидата. Отсутствующее или некорректное количество нужно исправить. Доступность строк из примера зависит от выбранного города и текущего API.

Исходные файлы не сохраняются приложением как отдельные вложения. Результат последнего разбора хранится в серверной сессии и используется для экспорта и черновика менеджеру.

## Excel, PDF и обращение менеджеру

Кнопки Excel/PDF находятся в панели инструментов консультанта и в корзине. В подборку входят:

- артикул и исходное название товара;
- подтверждённое количество, сохранённая цена и сумма;
- город, дата выгрузки и ссылка на товар;
- дата и значение курса при отображении в RUB/USD;
- отдельный раздел строк спецификации, которые ещё не покрыты количеством в корзине.

Неподобранные строки не входят в итоговую сумму. Если спецификацию редактировали только на экране, повторите разбор, чтобы экспорт получил актуальную серверную версию.

**Экспорт не обновляет цену через EKT API, не подтверждает ожидающее действие и не создаёт заказ.** Для пересчёта сохранённой цены KZT используется курс, доступный интерфейсу при экспорте. Файл не является счётом и не подтверждает резервирование.

XLSX содержит числовые количества и деньги, формулы сумм строк и итога с сохранёнными результатами. Артикулы записываются текстом, включая ведущие нули. Пользовательские строки сохраняются как текст, а не исполняемые формулы.

PDF создаётся в браузере со встроенным DejaVu Sans, переносами текста, ссылками и нумерацией страниц. Генерация документов не использует внешний сервис. Лицензия шрифта: [LICENSE-DejaVu.txt](public/fonts/LICENSE-DejaVu.txt).

«Вопрос менеджеру» формирует редактируемый текст с городом, корзиной, последней спецификацией и последними сообщениями диалога. Покупатель может скачать его и передать самостоятельно. Автоматической отправки письма или сообщения менеджеру нет.

## EKT AI: новый консультант

Сценарный обработчик диалога заменён генерацией ответов через модель с Chat Completions и function calling. Настройте серверные LLM_URL (полный HTTPS endpoint /chat/completions), LLM_API_KEY и LLM_MODEL. Модель должна поддерживать function tools и max_completion_tokens. Ключ не помещается в клиент, Git или сообщения чата. Без настроек чат показывает статус отключённого ИИ; прежние шаблонные консультации не включаются. Каталог и подтверждения корзины продолжают работать.

ИИ получает последние 8 сообщений, текущий вопрос, город и ограниченные данные каталога. Доступны только search_catalog и product_details; инструмента записи в корзину нет. Переход к покупке — через карточки и явное подтверждение. Ответы генерируются на RU/KK/EN; факты в карточках приходят с сервера. При сбое провайдера запрос можно повторить, история и корзина не подменяются выдуманным ответом. Максимум 4 обращения к модели, до 4 инструментов за шаг, общий тайм-аут запросов модели 45 секунд.

Проверка адаптера без платных запросов: node scripts/test-ai-consultant.mjs. Для живой проверки необходим ключ выбранного провайдера. Реальная генерация без ключа не проверена. Схема инструментов: https://developers.openai.com/api/docs/guides/function-calling
