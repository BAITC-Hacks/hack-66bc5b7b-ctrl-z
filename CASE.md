# Кейс №1 — консультант для ekt.kz

Покупателю электротехники недостаточно названия и цены: нужно проверить характеристики, остатки в нужном городе и возможность замены. Сейчас эти вопросы принимает менеджер. Задача хакатона — перенести типовые консультации в чат и помочь собрать корзину, оставив решение за покупателем.

Пример: покупатель пишет «Есть товар 515291?». Ассистент находит карточку, запрашивает свежие данные, показывает цену, остатки по складам и характеристики. На «Добавь 2 шт.» сначала появляется предложение с товаром, количеством и суммой. После «Да, добавь» сервер ещё раз проверяет цену и остаток и обновляет корзину. Отмена ничего не добавляет.

## Что показывает прототип

- Реальные данные: 100 товаров из первых пяти страниц API, снимок от 23 сентября 2026 года. Цена и наличие перепроверяются при открытии карточки и перед добавлением.
- Поиск по внутреннему ID, артикулу, артикулу производителя, названию и характеристикам. Короткие уточнения номинала и полюсов учитывают предыдущий запрос.
- Ответы о наличии, характеристиках и складах. Противоречия исходных данных выделяются: у товара 515291 название указывает 160 А, отдельное поле — 250 А.
- Предварительные аналоги с объяснением: одна группа каталога, минимум два совпавших ключевых параметра, отсутствие известных расхождений. Это не инженерное заключение о взаимозаменяемости.
- Условия покупки с источником на сайте. Если API не передаёт сертификат или минимальную сумму заказа, ассистент прямо сообщает об этом.
- Демонстрационная корзина с серверным хранением, проверкой остатка и одноразовым подтверждением. Ссылка открывает её актуальное состояние.
- Чтение текстовых PDF, DOCX, XLSX, TXT и CSV. Распознанный текст сначала показывается пользователю для проверки. JPEG подключается к мультимодальной модели после настройки ключа.

## Граница готовности

У пользователя пока нет ключа ИИ. Поэтому демонстрация отвечает по алгоритмам поиска и проверенным шаблонам. Подготовлен серверный адаптер модели для понимания запросов и распознавания фото; этот путь без ключа не проверен. Модель не управляет корзиной и не определяет цену или остаток.

Предоставленный API описывает только чтение каталога. Корзина прототипа самостоятельная: она не создаёт реальный заказ и не резервирует товар. Для внедрения необходимы API корзины ekt.kz, привязка к сессии покупателя и согласованный способ установки виджета. Это рабочий прототип для демонстрации, а не установленный на ekt.kz сервис.

## Сценарий защиты

1. «Есть товар 515291?» — показать реальные данные и предупреждение о расхождении номинала.
2. «Подбери автомат Legrand», затем «40 А», затем «3 полюса» — сузить подбор.
3. «Подбери аналог 24166» — показать отсутствующую позицию и кандидата на замену.
4. Открыть карточку 515291, выбрать 2 штуки и нажать «Добавить…». Корзина остаётся пустой до подтверждения.
5. Отменить, затем повторить и подтвердить. Открыть корзину по ссылке. Повторное подтверждение не дублирует добавление.
6. Запросить 100000 штук — показать отказ из-за остатка.
7. Выбрать город и показать остатки; отметить два товара и открыть сравнение.
8. Загрузить спецификацию DOCX, XLSX или CSV; проверить строки, товары и количества, подготовить пакетное добавление.
9. Показать изменение количества и удаление из корзины через подтверждение.
10. Открыть «Вопрос менеджеру» и редактируемый черновик, затем `/widget-demo`.

На пилоте стоит измерять время до ответа, долю вопросов без менеджера, точность поиска и переходы из консультации в корзину. В прототипе эти бизнес-метрики не измерялись.

При недоступности внешнего API карточки и сравнение явно подписаны как сохранённые данные. Добавление и изменение количества блокируются до успешной свежей проверки. Для защиты без сети используйте каталог, сравнение, разбор спецификации, черновик и виджет; успешное добавление показывайте только при работающем EKT API.

Дополнения для защиты: переключите «Рус / Қаз», задайте «Legrand автоматын таңда», оцените ответ и перезагрузите страницу. После подтверждённого подбора скачайте Excel и PDF. Покажите итог и отдельный раздел неразобранных строк; выгрузка сама не меняет корзину.
